# ~ajhalili2006's homelab infrastructure as code

The monorepo of @ajhalili2006's homelab IaaC and other infra related stuff.

**Docs**: <https://wiki.andreijiroh.dev/garden/infraops/homelab>

## Directory Map

* [`docker`](./docker/) - Docker Compose files of chaos and custom images outside [the `docker-images` repo](https://github.com/andreijiroh-dev/docker-images)
* [`dns`](./dns/) - DNS records for Cloudflare and deSEC, managed via octoDNS.
* [`utils`](./utils/) - Utility scripts
